# API

Base URL: `http://localhost:8000`

## Health

`GET /health`

## Auth

- `POST /api/auth/signup`
- `POST /api/auth/login`

## Reports

- `POST /api/report/upload`
- `POST /api/report/analyze`
- `GET /api/report/history`
- `GET /api/report/compare`

## Chat

- `POST /api/chat`

## Profile and Settings

- `GET /api/profile`
- `GET /api/settings`
